# Day 3 - JavaScript Practice

## Project Overview
This project contains a collection of JavaScript practice problems and exercises covering fundamental programming concepts.

## Files

### index.html
A basic HTML template that:
- Sets up proper document structure with DOCTYPE and meta tags
- Includes meta charset (UTF-8) and viewport settings for responsive design
- Has a reference to `styles.css` for styling (can be created later)
- Links to `script.js` for JavaScript functionality

### script.js
A comprehensive JavaScript practice file containing solutions to various problems organized by topic:

#### **Variables** (Problems 1-3)
1. **Swap two variables** - Uses arithmetic operations (a+b, a-b) to swap values without a third variable
2. **Personal Information** - Creates variables for name, age, and city; prints a formatted sentence
3. **Temperature Conversion** - Converts Celsius to Fahrenheit using the formula: F = C × 9/5 + 32

#### **Operators** (Problems 4-7)
4. **Even/Odd Check** - Uses the modulus operator (%) to determine if a number is even or odd
5. **Rectangle Calculations** - Calculates area (length × width) and perimeter (2×(length+width))
6. **Find Largest Number** - Compares three numbers using comparison operators to find the largest
7. **Swap Using Math** - Swaps two numbers using addition and subtraction without a third variable

#### **Conditional Statements** (Problems 8-11)
8. **Number Classification** - Checks if a number is positive, negative, or zero using if-else
9. **Grading System** - Assigns letter grades (A/B/C/F) based on a score (0-100)
10. **Leap Year Checker** - Determines if a year is a leap year using multiple conditions
11. **Triangle Validator** - Checks if three sides form a valid triangle and classifies it as equilateral, isosceles, or scalene (incomplete in current file)

## Topics Covered
- Variable declaration and manipulation
- Arithmetic and comparison operators
- Control flow with if-else statements
- Console logging for output
- String concatenation
- Basic mathematical formulas

## How to Use
Open `index.html` in a web browser, then open the browser's Developer Console (F12 or Right-click → Inspect → Console) to see the output of all JavaScript problems.
